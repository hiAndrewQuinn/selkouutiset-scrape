# Lost editions: days Yle published a Selkouutiset edition that no longer exists
# anywhere (not on yle.fi, not in the Wayback Machine, not in this archive).
# Their day folders hold the previous edition, carried forward like any gap; the
# archive website lists them greyed out as "lost media" instead of linking them.
#
# Format: YYYY-MM-DD<TAB>reason. Lines starting with # are ignored. Edit by hand
# if a copy turns up (remove the line after filing it with `archive backfill`).
#
# Generated 2026-11-24 from the history backfill (tools/history.py):
# - before 2023-10-26, a carried-forward day is listed unless it falls on a day
#   Yle normally skips (20 Dec - 7 Jan, Easter, May Day, Ascension, Midsummer,
#   Independence Day);
# - from 2023-10-26 the scraper saw every day itself, so only editions known to
#   have existed are listed.
#
# 2026-11-26: a second sweep recovered 292 of the 316 days listed then. It
# probed yle.fi article IDs (assigned in increasing order) around where each
# edition should be, and read Common Crawl's index of the old site's URLs; a
# page was filed only if yle.fi serves it dated (datePublished) on its day.
#
# Later on 2026-11-26 a third pass recovered 21 more. 19 had titles with typos
# ("Perjantai 19.1. 2018", "Tiistai 21.2.2020" for 21.1., "Sunnuntai
# 21.4.2109") or sat just outside the probe window; their datePublished is
# their day. 2019-03-07 and 2019-04-14 were posted after midnight (08:37 the
# next morning, and 00:01), so datePublished names the next day, which has an
# edition of its own; they were filed by hand under the day their title names.
#
# A fourth pass the same day found the last three days' fates:
# - 2022-05-01 is yle.fi/a/3-12425039, titled "Sunnunta 1.5.2022 (radio)"
#   (weekday misspelt), and 2022-07-06 is 3-12526285, titled "Keskiviikko
#   5.7.2022" (no (radio) suffix, date of the day before). Both were in the
#   probe cache all along; the title filter missed them. Both are filed.
# - 2023-03-18 appears never to have been published as a web edition. The
#   Wayback Machine's capture of Yle's own Selkouutiset front page on
#   2023-03-20 12:43 lists every edition from 10.3. to 19.3. except the 18th
#   (17.3. radio+tv, then 19.3.); a crawl of the whole list on 2023-04-17 has
#   none either, Common Crawl has no lauantai_1832023 URL, and every ID between
#   the 17th's and 19th's editions (3-12689908..27) is 404 and was never
#   archived. It is a carried-forward gap like a holiday, not lost media.
#
# No edition from 2016-09-04 onward is known to be lost.
#
# 2026-11-27: the history backfill was extended back to 2014-09-20, the
# earliest edition yle.fi still serves (tools/history.py now also reads the
# 2014-2016 /uutiset/<weekday>_ slugs). Of the days it carries forward, 17
# fall on days Yle usually skips; the 20 below did not, by the same rules as
# above. The article-ID probe is no help this far back: in 2014 Yle's IDs
# were shared with all its other content, and 1,486 of 1,497 IDs probed
# around 2014-10-28 were 404s with no edition among the rest.
